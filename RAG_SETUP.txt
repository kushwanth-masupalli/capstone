------------------------------------------------------------
1. INSTALL DEPENDENCIES
------------------------------------------------------------
pip install pinecone sentence-transformers

------------------------------------------------------------
2. PINECONE SETUP
------------------------------------------------------------
- Sign up at https://www.pinecone.io/
- Get your API key from the dashboard
- Set it as environment variable:
    Windows:  set PINECONE_API_KEY=your_key_here
    Linux:    export PINECONE_API_KEY=your_key_here

Index config:
    Name:       chest-xray-rag
    Dimension:  384 (for all-MiniLM-L6-v2)
    Metric:     cosine
    Cloud:      aws
    Region:     us-east-1

------------------------------------------------------------
3. EMBEDDING MODEL
------------------------------------------------------------
    Model:  all-MiniLM-L6-v2
    Dim:    384
    Library: sentence-transformers

    from sentence_transformers import SentenceTransformer
    embedder = SentenceTransformer('all-MiniLM-L6-v2')
    embeddings = embedder.encode(texts)

------------------------------------------------------------
4. DOCUMENT TYPES TO INDEX
------------------------------------------------------------

A) PRIOR CASES (from IU X-Ray training reports)
   - Source: data/indiana_reports.csv + data/indiana_projections.csv
   - Use ONLY training set reports (never test set — data leakage)
   - Each document = one case combining:
       * Problems (diagnosis labels)
       * Indication (reason for exam)
       * Comparison (prior exam info)
       * Findings (detailed description)
       * Impression (clinical summary)
   - Filter out cases with < 20 chars of text
   - Document structure:
       {
           "id": "case_{uid}",
           "text": "Diagnosis: ...\nIndication: ...\nFindings: ...\nImpression: ...",
           "metadata": {
               "source": "iu_xray_prior_case",
               "uid": "...",
               "problems": "...",
           }
       }

B) RADIOLOGY GUIDELINES (curated reference texts)
   - One document per condition in the label list
   - Include: Cardiomegaly, Pleural Effusion, Pneumonia,
     Atelectasis, Granuloma, COPD/Emphysema, Pneumothorax,
     Nodule, Opacity, Spine, Lung, Aorta, Catheters, Markings
   - Each doc = 3-5 sentence clinical reference
   - Document structure:
       {
           "id": "guideline_{hash}",
           "text": "Clinical Reference - Cardiomegaly:\n...",
           "metadata": {
               "source": "radiology_guideline",
               "condition": "Cardiomegaly",
           }
       }

------------------------------------------------------------
5. TEXT CHUNKING RULES
------------------------------------------------------------
    Min words per chunk:     50
    Max words per chunk:     250
    Overlap between chunks:  30 words
    Split at sentence boundaries when possible

------------------------------------------------------------
6. INDEXING PROCESS
------------------------------------------------------------
    1. Build documents list (prior cases + guidelines)
    2. Embed all documents with SentenceTransformer
    3. Upsert to Pinecone in batches of 100
    4. Verify with index.describe_index_stats()

    pinecone code:
        from pinecone import Pinecone, ServerlessSpec
        pc = Pinecone(api_key=API_KEY)
        pc.create_index(
            name="chest-xray-rag",
            dimension=384,
            metric="cosine",
            spec=ServerlessSpec(cloud="aws", region="us-east-1")
        )
        index = pc.Index("chest-xray-rag")
        index.upsert(vectors=[{"id": ..., "values": ..., "metadata": ...}])

------------------------------------------------------------
7. RETRIEVAL FUNCTION
------------------------------------------------------------
    Input:  predicted_findings from classifier (e.g. ["Cardiomegaly", "Pleural Effusion"])
    Output: formatted text string for LLM prompt

    Process:
        1. Join findings into query string: "Cardiomegaly Pleural Effusion"
        2. Embed query with same SentenceTransformer model
        3. Query Pinecone for top-k results
        4. Filter by source type if needed
        5. Format as structured text

    Query code:
        query_emb = embedder.encode(["cardiomegaly pleural effusion"])[0]
        results = index.query(
            vector=query_emb.tolist(),
            top_k=6,
            include_metadata=True
        )

    Output format for LLM prompt:
        "Relevant Clinical Guidelines:
         - Clinical Reference - Cardiomegaly: ...
         - Clinical Reference - Pleural Effusion: ...

         Similar Prior Cases:
         - Diagnosis: Cardiomegaly;Pleural Effusion
           Findings: The cardiac silhouette is enlarged...
         - ..."

------------------------------------------------------------
8. PATIENT HISTORY MODULE
------------------------------------------------------------

A) DATA SOURCES
   - 'comparison' field from reports CSV (e.g. "Compared to prior exam from 2019")
   - 'indication' field (e.g. "Positive TB test", "Preop bariatric surgery")
   - Synthetic/simulated history for cases without real data

B) STRUCTURED SCHEMA
    {
        "uid": "1234",
        "age": 54,
        "sex": "F",
        "indication": "Shortness of breath",
        "comparison": "Prior CXR 6 months ago showed resolved right pleural effusion",
        "previous_findings": "Prior CXR 6 months ago showed resolved right pleural effusion. Current findings: ...",
        "lab_values": {"WBC": "12.4", "CRP": "elevated"},
        "is_synthetic": false
    }

C) FORMAT FOR LLM PROMPT
    "Patient History: 54-year-old female.
     Indication: Shortness of breath.
     Comparison: Prior CXR 6 months ago showed resolved right pleural effusion.
     Lab values: WBC 12.4, CRP elevated."

D) CONTRADICTION TEST CASES (20-30 cases for Phase 8)
    Build cases where history contradicts what a report might say:
    1. History: "healed rib fractures" → Report should NOT say "new fracture"
    2. History: "resolved pleural effusion" → Report should NOT say "effusion present"
    3. History: "normal cardiac silhouette" → Report should NOT say "cardiomegaly"
    4. History: "calcified granuloma, no active disease" → Report should NOT say "active pneumonia"
    5. History: "normal CXR 2 weeks ago" → Report should NOT say "new cardiomegaly"

    Save as: data/contradiction_test_cases.json

------------------------------------------------------------
9. FULL PIPELINE FLOW (Phase 7 integration)
------------------------------------------------------------

    Image → Classifier (Phase 3) → Predicted Findings
                                          ↓
                    ┌───────────────────────┐
                    │  RAG Retrieval        │
                    │  (query = findings)   │
                    │  → guidelines chunks  │
                    │  → prior case chunks  │
                    └───────────────────────┘
                                          ↓
                    ┌───────────────────────┐
                    │  Patient History      │
                    │  (from Phase 6)       │
                    └───────────────────────┘
                                          ↓
                    ┌───────────────────────┐
                    │  LLM Prompt:          │
                    │  [Image]              │
                    │  [Retrieved Context]  │
                    │  [Patient History]    │
                    │  [Instruction]        │
                    └───────────────────────┘
                                          ↓
                              Generated Report
